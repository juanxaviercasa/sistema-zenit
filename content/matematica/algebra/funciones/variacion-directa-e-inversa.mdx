# Variación directa e inversa de dos variables

<Objetivo>

Definir la variación directa e inversa entre dos variables como funciones $y=kx$ y
$y=k/x$, y demostrar el criterio que permite reconocerlas a partir de una tabla de
valores.

</Objetivo>

## Marco teórico

$y$ **varía directamente** con $x$ si $y=kx$ para alguna constante $k\neq0$ (la
**constante de proporcionalidad**). $y$ **varía inversamente** con $x$ si
$y=\dfrac kx$ (equivalentemente $xy=k$), para alguna constante $k\neq0$.

**Enunciado.** $y$ varía directamente con $x$ si y solo si $\dfrac yx$ es
constante para todo $x\neq0$ del dominio.

**Demostración.** ($\Rightarrow$) Si $y=kx$, entonces $\dfrac yx=\dfrac{kx}x=k$
(constante), para todo $x\neq0$. ($\Leftarrow$) Si $\dfrac yx=k$ (la misma
constante) para todo $x\neq0$ considerado, despejando: $y=kx$. $\blacksquare$

**Enunciado.** $y$ varía inversamente con $x$ si y solo si $xy$ es constante.

**Demostración.** ($\Rightarrow$) Si $y=\dfrac kx$, entonces $xy=x\cdot\dfrac
kx=k$ (constante). ($\Leftarrow$) Si $xy=k$ (constante) para todo $x$
considerado, despejando: $y=\dfrac kx$. $\blacksquare$

Estos criterios —verificar si $y/x$ o $x\cdot y$ se mantiene constante en una
tabla de valores— son exactamente la generalización, en lenguaje de funciones, de
las magnitudes directa e inversamente proporcionales estudiadas en Aritmética.

## Ejemplos resueltos

<EjemploResuelto numero={1} dificultad="basico">

**Enunciado.** Si $y$ varía directamente con $x$, y $y=15$ cuando $x=3$, halla
$k$ y la fórmula de $y$.

**Solución.** $k=y/x=15/3=5$. $y=5x$.

</EjemploResuelto>

<EjemploResuelto numero={2} dificultad="basico">

**Enunciado.** Si $y$ varía inversamente con $x$, y $y=4$ cuando $x=6$, halla $k$
y la fórmula de $y$.

**Solución.** $k=xy=6\times4=24$. $y=24/x$.

</EjemploResuelto>

<EjemploResuelto numero={3} dificultad="intermedio">

**Enunciado.** Determina si la tabla $(x,y)$: $(2,10)$, $(3,15)$, $(5,25)$
representa variación directa, inversa, o ninguna.

**Solución.** $y/x$: $10/2=5$, $15/3=5$, $25/5=5$ — constante. Es variación
directa con $k=5$.

</EjemploResuelto>

<EjemploResuelto numero={4} dificultad="uni">

**Enunciado.** Determina si la tabla $(x,y)$: $(2,12)$, $(3,8)$, $(4,6)$
representa variación directa, inversa, o ninguna.

**Solución.** $y/x$: $6,\ 2{,}67,\ 1{,}5$ — no es constante, no es directa. $xy$:
$2\times12=24$, $3\times8=24$, $4\times6=24$ — constante. Es variación inversa
con $k=24$.

</EjemploResuelto>

## Problemas propuestos

<Problema numero={1} nivel="basico">

Si $y$ varía directamente con $x$, y $y=21$ cuando $x=7$, halla $y$ cuando
$x=10$.

<Solucion>

$k=21/7=3$. $y=3(10)=30$.

</Solucion>
</Problema>

<Problema numero={2} nivel="basico">

Si $y$ varía inversamente con $x$, y $y=5$ cuando $x=8$, halla $y$ cuando $x=4$.

<Solucion>

$k=8\times5=40$. $y=40/4=10$.

</Solucion>
</Problema>

<Problema numero={3} nivel="intermedio">

Determina si $(x,y)$: $(1,8)$, $(2,4)$, $(4,2)$ es directa, inversa, o ninguna.

<Solucion>

$xy$: $8,8,8$ — constante. Es variación inversa con $k=8$.

</Solucion>
</Problema>

<Problema numero={4} nivel="intermedio">

Determina si $(x,y)$: $(1,3)$, $(2,7)$, $(3,11)$ es directa, inversa, o ninguna.

<Solucion>

$y/x$: $3,\ 3{,}5,\ 3{,}67$ — no constante. $xy$: $3,14,33$ — no constante.
Ninguna de las dos (es afín, $y=4x-1$, no una variación pura).

</Solucion>
</Problema>

<Problema numero={5} nivel="uni">

Demuestra que si $y$ varía directamente con $x$ (con constante $k_1$) y $z$ varía
directamente con $y$ (con constante $k_2$), entonces $z$ varía directamente con
$x$.

<Solucion>

$y=k_1x$ y $z=k_2y=k_2(k_1x)=(k_1k_2)x$. Como $k_1k_2$ es una constante, $z$ varía
directamente con $x$, con constante $k_1k_2$. $\blacksquare$

</Solucion>
</Problema>

<Problema numero={6} nivel="uni">

Demuestra que si $y$ varía inversamente con $x$, y $z$ varía inversamente con $y$,
entonces $z$ varía **directamente** con $x$.

<Solucion>

$y=\dfrac{k_1}x$ y $z=\dfrac{k_2}y=\dfrac{k_2}{k_1/x}=\dfrac{k_2x}{k_1}=
\left(\dfrac{k_2}{k_1}\right)x$. Como $k_2/k_1$ es una constante, $z$ varía
**directamente** con $x$. $\blacksquare$ (Componer dos variaciones inversas
produce una variación directa.)

</Solucion>
</Problema>

## Errores frecuentes

<ErroresFrecuentes>

- **Confundir "variar directamente" con "ser función creciente"** — la variación
  directa exige específicamente $y=kx$ (proporcionalidad), no solo que $y$
  aumente cuando $x$ aumenta.
- **Verificar solo un par de la tabla** — hay que comprobar que $y/x$ (o $xy$) es
  la **misma** constante para **todos** los pares, no solo uno.
- **Pensar que toda relación es directa o inversa** — muchas funciones (como las
  afines con término independiente distinto de cero) no son ninguna de las dos.
- **Confundir las fórmulas de composición** — componer dos variaciones directas da
  otra directa; componer dos inversas da una **directa** (no una inversa).

</ErroresFrecuentes>
